The second test release of BlackBoxus: fixes for what testers found on phones, and saving, exporting and keyboard filling.

> **Please read first.** BlackBoxus hasn't been independently audited yet. Use test accounts and passwords you can afford to lose, and keep your current password manager while you try it.

> **Update every device to this version.** The next release changes how some item details are stored. This version keeps such items safe and shows the rest of the vault; 0.1.0 can't show a vault that has one.

## What to download

| You have | File |
| --- | --- |
| Windows 10 or 11 | `BlackBoxus-windows-x64-setup.exe` |
| Android 9 or later | `BlackBoxus-android-arm64.apk` |
| Debian, Ubuntu or Mint | `BlackBoxus-linux-amd64.deb` |
| Other Linux | `BlackBoxus-linux-x86_64.AppImage` |
| Chrome, Edge or Brave | `BlackBoxus-extension-chrome.zip` |
| Firefox 128 or later | `BlackBoxus-extension-firefox.zip` |

Check each file against `SHA256SUMS.txt` before installing (see "Check your download" on the [download page](https://blackboxus.pages.dev/download#verify)). The Android app installs over 0.1.0 and keeps your data.

## Fixed

- **Phones felt slow and froze.** Syncing held up everything else, including opening an item and the Lock button. It now syncs in the background, and the app shows the vaults saved on the phone straight away.
- **Pages zoomed and scrolled like a website**, with a white block at the bottom. Fixed.
- **The app stayed open after leaving it.** Locking is now done by the app itself when Android says it left the screen. The fingerprint prompt, camera and file picker don't count as leaving.
- **"Strong" under 12 characters, and Continue did nothing.** A short password now says "Too short", and the screen says what's still needed before you can continue.
- **The Secret Key looked like several codes.** It's shown as one key, with dashes only to make copying easier.
- Every setting now says in one line what it does.
- Two libraries the apps use had security fixes (`cookie`, `url`).
- Updated Tauri, the post-quantum encryption and signature libraries (ML-KEM, ML-DSA), and `zeroize`, which erases keys from memory.

## New

- **Save logins from other apps (Android).** After signing in somewhere, choose **Save** in Android's prompt, then confirm in BlackBoxus. An existing login for the same site and username gets the new password.
- **Fill from the keyboard (Android 11+).** Keyboards that support it show "Fill with BlackBoxus" in their suggestion strip.
- **Autofill help.** Settings › Autofill shows what happened the last time an app asked, and whether Chrome is set to use BlackBoxus, with a button to that Chrome setting.
- **Export.** Settings › Export (phone) or **Export vaults** (desktop): an encrypted `.bbx` file locked with a password you choose, or a plain CSV for moving elsewhere. Import reads `.bbx` files back.

## What to try

1. Install over 0.1.0 and check your vaults are all there.
2. Leave the app and come back: with **Lock after: straight away** it should ask to unlock; with a longer time, only after that long.
3. Sign in to an app or site you haven't saved, choose **Save**, and check the login appears.
4. Export to `.bbx`, then import it into a test vault.

## Known limits

- Mac, iPhone and iPad apps aren't in this release.
- The browser extension isn't in the Chrome Web Store or Firefox Add-ons yet.
- Saving from other apps needs BlackBoxus to be unlocked; if it's locked, you're sent to unlock it and the save finishes when you come back.

## Found a problem?

[Open an issue](https://github.com/ktnreddy/BlackBoxus/issues/new/choose), and never paste a password, your Secret Key or anything from your Emergency Kit. If it could put someone's passwords at risk, use **Report a security problem privately** instead.
